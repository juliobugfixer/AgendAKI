# 🎉 AgendAKI – Plataforma de Aluguel de Salões de Eventos

Bem-vindo ao repositório do **AgendAKI**!

O **AgendAKI** é um protótipo de interface para uma plataforma web que venho trabalhando com o objetivo de **simplificar a busca, comparação e reserva de salões de eventos**, proporcionando uma experiência prática, rápida e intuitiva para clientes e proprietários.

---

## ✨ Funcionalidades

* 🔍 Pesquisa de salões de eventos
* 🏢 Visualização de informações e detalhes dos espaços
* 📅 Interface para agendamento e reservas
* 📱 Design responsivo para diferentes dispositivos
* 🎨 Layout moderno e focado na experiência do usuário
* ⚡ Navegação simples e intuitiva

## 🎯 Objetivo

O objetivo deste projeto é apresentar um protótipo funcional da interface do **AgendAKI**, validando a experiência do usuário e servindo como base para o desenvolvimento da plataforma completa de gerenciamento e aluguel de salões de eventos.
